## 二、发起扫描

### 单站点扫描

1. 点击左侧菜单 **「发起扫描」**
2. 输入目标 URL: `https://example.edu.cn`
3. 选择扫描类型:
   - **首页扫描**: 仅检测首页（推荐用于日常监测）
   - **全站扫描**: 深度爬取全站
   - **深度扫描**: 最全面检测
4. 点击 **开始扫描**
5. 等待扫描完成，查看结果

### 扫描结果解读

| 威胁等级 | 含义 | 建议 |
|---------|------|------|
| 🔴 严重 | WebShell、暗链等严重威胁 | 立即处理 |
| 🟠 高危 | 敏感信息泄露、后门 | 尽快处理 |
| 🟡 中危 | 配置问题、可疑URL | 定期处理 |
| 🔵 低危 | 轻微违规 | 观察 |

## 三、批量扫描

适合对多个站点统一进行安全监测。

### 使用步骤

1. 点击 **「批量扫描」**
2. 选择输入方式:
   - **文本框输入**: 每行一个 URL
   - **文件导入**: 上传 URL 列表文件
3. 选择扫描类型
4. 点击 **开始批量扫描**

### 批量扫描进度

- 实时显示: 总数 / 已完成 / 进行中
- 可随时 **暂停** 或 **终止** 任务
- 完成后可导出统一报告

---

## 四、定时任务

设置周期性自动扫描，减少人工操作。

### 创建定时任务

1. 点击 **「定时任务」**
2. 点击 **「新建定时任务」**
3. 填写配置:
   - **任务名称**: 如"每周一例行扫描"
   - **目标URL**: 扫描对象
   - **扫描类型**: 选择类型
   - **执行周期**: Cron 表达式或快捷选项
     - 每天 8:00: `0 8 * * *`
     - 每周一 8:00: `0 8 * * 1`
     - 每月1号 8:00: `0 8 1 * *`
4. 保存

### 管理定时任务

- 查看下次执行时间
- 手动立即执行
- 编辑/删除任务

## 六、规则管理

管理扫描检测规则。

### 内置规则

平台预置了多种检测规则，涵盖:
- 暗链模式识别（JAVAV、MORE18 等赌博关键字）
- WebShell 特征码
- 敏感文件检测
- 违规内容检测

### 自定义规则

如需添加自定义检测规则，请联系管理员修改 `Config/config_rulefind.py` 配置文件。

## 七、资产发现 🛰️

对内网 IP 段和域名进行全面资产梳理。

### IP 段扫描

1. 进入 **「资产发现」**
2. 点击 **「添加 IP 段」**
3. 填写:
   - 名称: 如"教学楼网络"
   - IP 段: `10.8.0.0/16`
   - 端口: `80,443,8080,5188`
4. 点击扫描

### 域名爬取

1. 输入主域名: `example.edu.cn`
2. 选择是否递归爬取子域名
3. 点击开始爬取

### SSL 证书导入

将抓取的 SSL 证书 PEM 内容粘贴进来，系统自动提取 SAN 域名并创建资产记录。

### 资产列表

- 支持分页、搜索、过滤
- 可查看资产详情（IP/域名/证书/扫描状态）
- 支持批量删除

## 八、篡改监控

通过定期快照比对检测网页是否被篡改。

### 工作原理

1. 系统对目标页面截图并计算 Hash
2. 下次扫描时重新截图比对
3. 变化超过 30% 触发告警

### 查看告警

进入 **「资产发现」** → **「篡改告警」** 标签页，查看所有告警列表。

## 九、报告导出

### 导出格式

- **PDF 报告**: 适合打印和归档
- **JSON 格式**: 适合程序二次处理
- **HTML 报告**: 适合本地查看

### 导出单次扫描报告

1. 打开历史记录
2. 找到目标扫描
3. 点击 **「导出报告」**

### 批量导出

在批量扫描页面，完成后点击 **「导出全部报告」**

## 十、AI 智能分析（需安装 Ollama）

集成本地 Ollama 模型，对扫描结果进行智能分析。

### 安装 Ollama

```bash
# 安装 Ollama
curl -fsSL https://ollama.com/install.sh | sh

# 下载模型
ollama pull qwen3.5:4b

# 启动 Ollama 服务
ollama serve
```

### 使用 AI 分析

在扫描结果页面，点击 **「AI 分析」** 按钮，系统调用本地 Ollama 模型对威胁进行解读和建议。

## 十一、注意事项

> ⚠️ **系统约束**
> - 不扫描 FTP 端口 (21)
> - 不扫描 SCOW HPC 平台端口 (80)
> - 建议在业务低峰期执行大规模扫描
> - Worker Pool 最大 20 并发，队列容量 2000

> 🔒 **安全建议**
> - 定期修改管理员密码
> - 不要将默认密码告知无关人员
> - 定期查看扫描历史和告警
